# BST Brand Assets

Official brand assets repository for **BeacoSoft**. Contains all approved visual identity materials including logos, fonts, icons, stationery, mockups, and stock photography.

---

## Contents

### Brand Manual
`Brand Manual/Brand Manual.pdf`

The primary brand guidelines document. Covers logo usage, color palette, typography rules, and general visual identity standards. Start here before using any assets.

---

### Logo
`Logo/`

Available in three color formats:

| Format | Folder | Use Case |
|--------|--------|----------|
| SVG | `Logo/SVG/` | Preferred for all digital use — scales without quality loss |
| RGB | `Logo/RGB/` | Screen and web (JPG/PNG) |
| CMYK | `Logo/CMYK/` | Print production |

Variants include primary, secondary, icon-only, alternate (on blue/yellow), and monochrome (black/white) versions.

---

### Fonts
`Font/`

Two typefaces make up the BeacoSoft type system:

**Aquawax Pro** — `Font/aquawax_pro/`
- Display/heading typeface by Zetafonts
- Trial TTF files included: Regular Pictograms, DemiBold, DemiBold Italic
- See `AquawaxPro_Commercial information.pdf` before using in production

**Metropolis** — `Font/metropolis/`
- Body/UI typeface (SIL Open Font License)
- Full family: Thin, ExtraLight, Light, Regular, Medium, SemiBold, Bold, ExtraBold, Black — each with matching italic
- OTF format

## Usage Notes

- Always refer to the **Brand Manual** for color codes, clear space rules, and logo misuse guidelines before creating new materials.
- Use **SVG** logos and icons wherever possible; fall back to RGB PNG for digital and CMYK PNG for print.
- Aquawax Pro trial files are for evaluation only — obtain a commercial license before publishing.
- Metropolis is free to use under the [SIL Open Font License](Font/metropolis/SIL%20Open%20Font%20License.txt).
